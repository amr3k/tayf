## نبذة عن المشروع

طيف هو تطبيق سطح مكتب أصلي عالي الأداء، صُمم للمصممين والمطورين لمعاينة رسوم Lottie وفحصها والتحكم بها وتصديرها. مبني بالكامل بلغة Rust باستخدام **GPUI** (محرك واجهات مسرّع بالمعالج الرسومي من Zed) و **ThorVG** (محرك رسوميات متجهة عالي الأداء)، يتميز طيف بسرعة تشغيل فورية واستهلاك منخفض للذاكرة وعرض سلس ودقيق للرسوم المتحركة.

## المميزات

### الوظائف الأساسية
- **دعم صيغ متعددة**: افتح ملفات Lottie القياسية بصيغة JSON (`.json`) وحزم DotLottie الثنائية (`.lottie`)
- **طرق إدخال متعددة**: نافذة اختيار الملفات، وسائط سطر الأوامر (`tayf <المسار>`)، والسحب والإفلات
- **التحكم في التشغيل**: تشغيل/إيقاف، التنقل إطارًا بإطار، تفعيل التكرار، وتعديل السرعة (`0.5x`، `1.0x`، `1.5x`، `2.0x`)
- **شريط التنقل الزمني**: شريط تفاعلي لاستعراض الإطارات مع عرض رقم الإطار والوقت

### محرك التصدير
- **تصدير GIF**: تصدير سريع وعالي الجودة إلى صور GIF متحركة مع تخصيص الدقة ومعدل الإطارات والشفافية والتكرار
- **تصدير فيديو MP4**: تصدير فيديو بترميز H.264 مع تحكم في جودة CRF ومعدل الإطارات

### التخصيص المرئي
- **ألوان خلفية متوافقة مع السمة**: خصّص لون خلفية مساحة العرض بشكل منفصل للسمة الفاتحة والداكنة مع لوحة ألوان جاهزة
- **التكامل مع سمة النظام**: تنقل سلس بين أوضاع النظام والفاتح والداكن

### أدوات الفحص
- **عرض البيانات الوصفية**: تفاصيل شاملة عن الملف:
  - الأبعاد (العرض والارتفاع الأصليان)
  - معدل الإطارات (FPS)
  - المدة وإجمالي الإطارات
  - حجم الملف والصيغة

### التدويل
- **الإنجليزية والعربية**: دعم كامل لتخطيط RTL واللغة العربية عبر `rust-i18n`
- **التبديل الفوري**: تغيير اللغة مباشرة من الإعدادات

## التقنيات المستخدمة

| الفئة | التقنية |
|----------|-----------|
| **إطار الواجهة** | [GPUI](https://github.com/zed-industries/zed/tree/main/crates/gpui) (واجهة ثنائية الأبعاد مسرّعة بالمعالج الرسومي) |
| **محرك المتجهات / Lottie** | [ThorVG](https://www.thorvg.org/) (تنقيط متجهي عالي الأداء) |
| **اللغة** | Rust |
| **صيغ التصدير** | صور GIF متحركة (`gif` crate) و MP4 (`ffmpeg`) |
| **التدويل** | `rust-i18n` (الإنجليزية والعربية مع دعم RTL) |
| **مدير الحزم** | `cargo` |

## التثبيت والتطوير

### المتطلبات

- **بيئة Rust** (الإصدار 1.80 أو أحدث موصى به)
- **مترجم C++** (لبناء الواجهة الخلفية لـ ThorVG المكتوبة بـ C++)

### البناء والتشغيل

```bash
# استنساخ المستودع
git clone https://github.com/amr3k/tayf.git
cd tayf

# التشغيل في وضع التطوير
cargo run

# فتح ملف محدد مباشرة
cargo run -- /path/to/animation.json

# تشغيل اختبارات الوحدة
cargo test

# بناء النسخة النهائية المحسّنة
cargo build --release
```

الملف التنفيذي المستقل الناتج يوجد في `target/release/tayf`.
