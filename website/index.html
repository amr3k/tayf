A lightweight
Lottie viewer that feels instant.

Tayf is a high-performance native desktop app for designers and developers to preview, inspect, control and export Lottie animations. Built in Rust with GPUI and ThorVG — starts instantly, sips memory, renders silky-smooth.

GPL-3.0-or-later Rust 100% • GPUI • ThorVG

Everything you need — nothing you don’t

Focused on fast preview, precise control and clean export. No browser, no Electron, just native.

Multi-format Support

Open standard Lottie JSON .json and binary DotLottie .lottie archives with embedded assets via ZIP + manifest.

Playback Controls

Play/pause, step frame-by-frame, loop toggle, speed 0.5× · 1× · 1.5× · 2×. Interactive timeline scrubber with frame & time.

Frame Scrubbing

Scrub precisely through every frame. Display timestamps and frame numbers for pixel-perfect timing.

Export: GIF

Fast, high-quality animated GIF with custom resolution, FPS, transparency and loop settings (via gif crate).

Export: MP4

H.264 video export with adjustable CRF quality and frame-rate via FFmpeg sidecar. Perfect for decks & socials.

Canvas & Theme

Theme-aware canvas background with presets & custom hex. System / Light / Dark mode, respects OS preference.

Inspection

Metadata at a glance: dimensions (W×H), FPS, duration, total frames, file size & format. No guessing.

Internationalization

English & Arabic with full RTL layout via rust-i18n. Switch instantly from Preferences.

Multiple Inputs

File dialog and drag-and-drop. Whatever your flow.

Built for performance

Unlike Electron wrappers, Tayf is a true native binary — GPU-accelerated UI, C++ vector engine, zero webview.
